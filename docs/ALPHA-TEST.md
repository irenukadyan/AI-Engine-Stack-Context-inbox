# Alpha Test Guide

## Purpose

Validate whether developers repeatedly need a faster way to send phone-captured context into the local coding project where their AI agent is working.

## Invite message

> I am testing a free VS Code extension that lets you scan a QR code, send a screenshot/file/note from your phone, and place it directly into your active coding project. It is local-network only and does not run commands remotely. Would you try it on one real task this week and share feedback?

## Tester journey

1. Install the provided `.vsix` file.
2. Open a real coding project.
3. Start the mobile companion and scan the QR code.
4. Send at least one real screenshot, file, or note from the phone.
5. Ask the active coding agent to read `phone-transfer/INBOX.md`.

## Questions to ask

1. What were you trying to send, and why were you away from your laptop?
2. What did you use before this extension?
3. Did the extension save time or reduce steps? How?
4. Would you use it again next week? For which workflow?
5. What information would you be comfortable sending through it?
6. Would remote use outside your Wi-Fi be valuable enough to sign in and pair devices?

## Continue / stop criteria

Continue the product only if, among the first 5–10 testers:

- at least 3 use it on two separate real tasks; and
- at least 3 say they would miss it if it disappeared; and
- users can describe a repeatable situation beyond a one-off demo.

Do not treat compliments, downloads, or feature requests alone as validation.
